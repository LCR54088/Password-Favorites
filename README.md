# 🔒 密码保护导航页 (Password-Favorites)

一个完全独立的单 HTML 文件网站，带密码锁屏，支持在网页端自由添加、编辑和删除导航网站。

## ✨ 功能特性

- 🔑 **密码锁屏**：默认密码 `123456`，进入后可在网页端直接修改密码。
- 📁 **网站管理**：支持在网页端添加、编辑、删除网站卡片。
- 🖼️ **图标自定义**：图标支持 Emoji 表情（如 🐙、🚀）或图片链接。
- 🗂️ **分类聚合**：网站可按分类分组展示。
- 🔍 **实时搜索**：顶部搜索框可按名称、描述、地址或分类快速过滤。
- 📦 **导入导出**：支持一键导出当前所有网站数据为 JSON 备份，或导入恢复。
- 💾 **本地存储**：所有数据（密码哈希和网站列表）均保存在浏览器 `localStorage` 中，无需后端和数据库。

## 🔧 修改与配置

### 修改默认密码
默认密码为 `123456`。如需修改，有两种方式：
1. **在网页端修改**：进入页面后点击右上角「修改密码」直接操作。
2. **修改代码中的默认值**：在浏览器控制台执行 `generateHash('你的新密码')`，将得到的 SHA-256 字符串替换代码中的 `DEFAULT_PWD_HASH` 值。

## ⚠️ 安全注意事项

由于这是纯前端页面，密码验证和所有数据均存储在用户浏览器中。**请务必注意：**
- **任何人拿到你的链接，都可以通过查看源代码或修改浏览器缓存绕过密码。**
- 该页面适合**个人自用**（当作本地书签）或分享给信任的朋友。

## 🛠️ 技术实现
- 纯原生 HTML/CSS/JS，无任何第三方依赖和外部网络请求。
- 使用 Web Crypto API 的原生 JS 实现 SHA-256 密码哈希。
- 使用 `localStorage` 持久化存储网站列表。
